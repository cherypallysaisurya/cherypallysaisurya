## 🌟 Featured Work

### 🏡 Vacation-Rental Search Engine &nbsp;`Furray Logic`
A guest types a trip in plain words. The system finds matching homes and explains every match with proof from the listing's own text, photos, and reviews.

- 💸 Listings are analyzed once when added, for **under 2 cents each**, so search stays fast on a very large catalog
- ✅ Every fact is checked against the source text. Rule-based checks cut parsing errors by **about 80%** on a 198-case test suite
- 🗺️ Self-hosted routing on OpenStreetMap gives drive times with no per-lookup fee
- 🚢 Shipped on AWS with browser tests, a release gate for bad data, and one-step rollback

### ⭐ Star-Rating Models &nbsp;`Furray Logic`
Computer vision models that rate listings from photos and listing data. I ran **84 experiments** against expert ratings on a sealed test set, found that the production scorer had trained on part of its own evaluation data, and rebuilt the evaluation so the numbers can be trusted.

### ⚖️ AI Negotiation Broker &nbsp;`Furray Logic`
An AI that acts as a neutral expert between two parties. It favors neither side, and every outcome stays inside the rules both are bound by.

### 🎙️ MeetMind &nbsp;`In progress`
A live meeting copilot that listens, answers questions put to me, and suggests good questions to ask. Building it with my brother for **AWS re:Invent 2026**.

### 🤖 [ResuMatch](https://github.com/cherypallysaisurya/ResuMatch)
Web app using **LLMs, FastAPI, and React** to summarize, classify, and rank resumes against a job description, with AWS S3 storage and skill matching.

### 📅 [FAU Events App](https://github.com/cherypallysaisurya/fau-events)
Live campus event tracker built with **React, Node.js, and web scraping**, with location-aware reminders and a glowing building map.
